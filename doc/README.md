# VVooComfyUI 문서

이 디렉터리는 VVooComfyUI 프로젝트의 대화, 설계, 구현 계획, 검증 결과와 Git 작업 이력을 보관한다.

## 운영 규칙

- 프로젝트 관련 사용자·Assistant 대화는 `doc/conversation`에 기록한다.
- 설계 명세는 `doc/specs`에 기록한다.
- 구현 계획은 `doc/plans`에 기록한다.
- 단계별 조사·검증·커밋·푸시 결과는 `doc/work-log.md`에 누적한다.
- 각 작업 단계는 독립적인 Git 커밋으로 마무리하고 즉시 `origin`에 푸시한다.
- Comfy Desktop의 현재 캔버스를 변경하는 실환경 검증 전에는 현재 워크플로를 백업한다.
